Details about Xinux 
* This is the operating system kernel, which I wrote for QEMU and computers running Legacy BIOS. You can download and compile it. 
How to compile and run
* Run Command: make
* Run Command to Launch the QEMU virtual machine. : make qemu-usb
Please open VNC Viewer on your phone, type localhost:5900 and experience the operating system. 

Delete all the compiled source code: make clean
